# running in production -- `pip freeze` inside 7b4242d-0f70811-arm64 -- so this
# file describes a set that has actually served traffic rather than one a
# resolver might pick today.
#
# Why == everywhere, including transitives (#84): with `>=` constraints,
# rebuilding the same commit resolved whatever was newest that day. That makes
# ECR's immutable tags a fiction the moment anything is rebuilt -- the tag
# still means one image, but the commit no longer means one tag -- and it makes
# every rollback a guess about what you are rolling back to.
#
# Transitive pins matter as much as direct ones. A floating starlette or
# pydantic changes request handling underneath an unchanged FastAPI pin, which
# is exactly the kind of drift that is invisible until production.
#
# To move a version: change it here, rebuild, deploy, and let the deployment
# prove it. Do not edit this file to match a local environment.
